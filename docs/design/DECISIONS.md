## Detailed entries

**D-01 Target learner.** Decision: grades 6–8; curriculum/validation middle-school-first; playability outside band allowed without curriculum compromise. Alternatives: 4–5 (too pre-literate for the evidence loop), 9–12 (loses MS-LS2 fit). Rationale: MS-LS2 is a grades 6–8 NGSS bundle [S1]; Epic locks it. Consequences: reading-level gate (ACCEPTANCE §3.4), UI copy rules, hint register. Evidence: GAME-316; CURRICULUM_MAP §1. Status: FROZEN. Invalidation: Epic-level scope change only.

**D-02 Platform.** Decision: browser-first standalone static web; no backend, no accounts. Alternatives: Unity Web (D-11), native app (rejected: distribution/updates/school install friction). Rationale: games-site release system + accessibility needs + classroom context. Consequences: static-web shape constraints (D-25); restrictive CSP possible (ADR-12). Evidence: GAME-316 binding direction; games-site/docs/game-release-contract.md. Status: FROZEN. Invalidation: new product capability the web cannot deliver (Epic decision).

**D-03 Target browsers/devices.** Decision: R1 Chromebook-class, R2 360 px Android, R3 desktop (Chrome/Firefox/Safari current−2), R4 iPhone SE-class; release threshold passes on R1+R2+R3. Alternatives: fewer tiers (risk shipping broken classroom reality); oldest-supported-browser policy (unbounded test cost). Rationale: matches school reality + Epic's 360 px/200% zoom contract. Consequences: PERFORMANCE_BUDGETS §2 measurement obligations; degraded-mode paths tested. Evidence: GAME-316 a11y/responsive contract. Status: FROZEN. Invalidation: portfolio-wide matrix change.

**D-04 Pond Crisis scope.** Decision: one pond biome; 5 missions (M1 guided, M2 independent, M3/M4 variants, M5 revision path); 6–15 min sessions; no second biome until gates pass. Alternatives: more missions at shallower depth; more biomes (explicit Epic non-goal). Rationale: GAME-316 content lock ("first release must support at least…"); polish-over-breadth vision. Consequences: ER-04 authors exactly this set; ER-11 expands variants within it. Evidence: GAME-316; GDD §7. Status: FROZEN. Invalidation: ER-14 shows mission count insufficient for replayability target (D-23 dim 15) — would be a content addition, not redesign.

**D-05 Organism/role set.** Decision: Algae, Waterweeds, Water fleas, Mayflies, Snails, Bluegill, Dragonfly nymphs (7 groups / 6 trophic roles) + implicit decomposer layer; abiotic = nutrients (index), DO (mg/L), clarity (derived); temperature/water level frozen scenario inputs in v1. Alternatives: 6-group minimum without dragonflies (loses the invertebrate top-down lever), with duckweed (redundant with the lumped algae pool), fishless (loses the most familiar consumer + public DO-threshold anchor). Rationale: completes every Epic-required relationship (producers×2 with light competition, grazer chains, predator/prey ×2, sensitive/tolerant contrast, decomposition, resource limitation, nutrient cycling, DO); species chosen for modeled relationships + public scientific grounding, not looks (S10–S16). Consequences: SCIENCE_MODEL rules are the binding contract; adding species = new SIM_MODEL_VERSION. Evidence: SCIENCE_MODEL §4 (with sources). Status: FROZEN. Invalidation: ER-04 science review proves a role unteachable/unsourced → swap with equal topology, Jira-recorded.

**D-06 Science-model boundaries.** Decision: pedagogical causal model; explicit exclusions (N/P split, diurnal DO, stratification, toxins, seasonality, strict mass/energy quantities, etc.); no universal balance score; correlation-vs-causation protected by decoy missions. Alternatives: higher-fidelity compartment model (rejected: complexity without teaching gain, Epic forbids), purely qualitative rules (rejected: masks lags/magnitudes needed for prediction gameplay). Rationale: Epic's "explainable causal rules over unnecessary sophistication" + misconception mandates. Consequences: SCIENCE_MODEL §7 honesty notes become content obligations (ER-04/ER-05). Evidence: SCIENCE_MODEL §1, §7, §8. Status: FROZEN. Invalidation: independent science review (ER-04) finds an exclusion that creates a high-severity misconception — must fix by inclusion or by changed content framing.

**D-07 Tick/time model.** Decision: 1 tick = 1 model day; advance only via explicit actions (≤7/step, ≤60 auto-run); 60-tick mission horizon; causal lags via intermediate stocks + running averages; kernel has no clock. Alternatives: 1 tick = 1 hour (diurnal noise, worse M-2 risk); continuous time (determinism cost, no gain). Rationale: eutrophication responses are multi-day [S2/S3]; matches prediction-lag vocabulary; trivial determinism. Consequences: UX time controls as frozen; auto-run pacing is presentation-only. Evidence: SCIENCE_MODEL §2; TECHNICAL_DESIGN §D-2. Status: FROZEN. Invalidation: none foreseen; change = new SIM_MODEL_VERSION.

**D-08 Data units.** Decision: every learner-visible value is one of: index (0–100), relative abundance (0–100 vs typical spring), mg/L (DO only), days/weeks; storage = scaled integers (SCALE 1000; DO scale 10); indices never rendered as counts; no decimals except DO. Alternatives: floats (determinism risk), real-unit everything (false precision, unsupportable), counts of organisms (misleading aggregation). Rationale: GAME-317 "no false precision" + ER-03 determinism requirements. Consequences: kind labels mandatory in UI; parameter table carries unit semantics. Evidence: SCIENCE_MODEL §3, §9; TECHNICAL_DESIGN §D-3. Status: FROZEN. Invalidation: none in v1.

**D-09 Persistence.** Decision: versioned session/tab-local storage (`ecr-session-v1`) holding settings + active-mission snapshot + last summaries; memory fallback; refresh-survival via restore prompt; schema mismatch discards (no migration); nothing leaves the device. Alternatives: localStorage (survives tab close — more state than needed, more privacy surface), IndexedDB (overkill), no persistence (fails refresh-mid-mission expectation), Supabase (D-21 decline). Rationale: GAME-317 preferred direction; privacy-first posture with real utility. Consequences: TECHNICAL_DESIGN §D-7 is the normative contract ER-02 tests. Evidence: GAME-317 state/persistence decision block. Status: FROZEN. Invalidation: product decision requiring cross-device progress (Epic change + privacy review).

**D-30 Calibration discipline.** Decision: the science model's numbers are held to three rules. (1) **Mass-budget rules only** — every stock-to-stock transfer is a mass transfer, so the §5 loop identity is a machine-checked property rather than a promise, which is why R-12's production falls out of the mass budget instead of being a separate `p.reproduction`. (2) **The pristine pond is solved, never hand-set** — the watershed inflow is driven so the nutrient index rests on its scenario reference, and the resulting state must be a *stationary fixed point* (60-tick drift ≈ 0 on every stock), because a hand-set "baseline" that quietly drifts makes every §11-1 claim untestable (this session found the previous baseline drifting −9 on detritus while being described as stationary). (3) **The harness is the acceptance test** — `docs/design/evidence/calibration-sim.mjs` implements the rules independently of the kernel and asserts the §11 commitments, the sanity tests, the intervention directions and the loop identity; ER-03 may not calibrate a kernel against a parameter set the harness has not passed, and a failing harness is reported as a failing harness, never described as "candidate" progress. Alternatives: tuning by inspection (already produced two mutually inconsistent parameter sets), golden traces authored from the kernel (circular — the kernel is what is being calibrated). Consequences: the harness is committed alongside the documents and its failures are part of the package; any parameter change outside a declared range is a version event. Evidence: SCIENCE_MODEL §9/§9.1, EVIDENCE.md §5. Status: FROZEN. Invalidation: none for v1.

**D-31 F-2 resolution — decouple the bloom's growth from the nutrient pool (product-owner decision).** Decision: R-01's logistic ceiling is the **fixed self-shading capacity** `p.maxAlgae`, the nutrient pool enters as a **saturating supply factor** and as the **hard mass constraint** (`uptake ≤ nutrients`), and R-01b sheds the part of the bloom's own losses that its growth no longer covers, at a frozen rate. `SIM_MODEL_VERSION`/`PARAM_SET_VERSION` become `pond-crisis-1.2` / `pc1-params-1.2`; `p.nutrientHalfSaturation` is added; `p.bloomCrashThreshold` is retired from the frozen rule (kept as measured-negative evidence in R-01c). Alternatives, each measured before the decision: **(a)** raise `p.algaeGrowthRate`'s legal range top above 0.30 — the settled bloom moved only 71 → 74 at `r` = 0.45 and the healthy-baseline band broke first; **(b)** raise the nutrient index's internal cap above 100 — inert, because the pool is never the binding constraint on the bloom (the trace shows the pool strictly above it) and the cap is the source of the F-5 clamp damage; **(c)** restate the §11-2 bloom window as a baseline multiple — removes one contradiction but leaves clarity, DO and the consumer windows unreachable, because under a pool-keyed R-01 the mass die-back that should deliver the detritus pulse never happens at all. Rationale: (d) is the only option of the four that makes the canonical chain *reachable*, and it is what the documents already promised in R-04 ("bloom algae die en masse when nutrient supply collapses") and in packet A's disposition #3 ("decay-from-excess… ceiling = 0 ⇒ exponential crash") — the frozen rule had simply never implemented it. Consequences: R-01/R-01b/R-04 restated; §6.5 added (the per-tick evaluation order was referenced but never written); the harness defaults to the new structure and still **fails 18 of 45 checks**, so the *values* stay provisional and the numeric demonstration remains an **ER-04** gate item (F-6 is the diagnosed blocker: the nutrient loop's return flux keeps the pool high and starves the die-back of its shortfall). Evidence: SCIENCE_MODEL §9/§9.1, EVIDENCE.md §5.3–5.4; the decision was put to the product owner as a choice among (a)–(d) and (d) was selected. Status: FROZEN for the structure; INVALIDATION for the values would be ER-04 evidence that a different growth limitation reproduces the chain more faithfully — that would be a new SIM_MODEL_VERSION, not a retune.
